该目录下为早期设计，已经抛弃

该设计由于将条目数不确定导致大小长度不确定的元数据区放在数据区之前，导致难以进行管理和读写
+-----------+
|   文件头   |
+-----------+
|   元数据   |
+-----------+
|   数据区   |
+-----------+

一开始的设计是元数据的最后一条紧跟着数据区，但是考虑到数据区中可能有不断新增的归并段，将元数据区改为可以容纳固定条数
且由于早期设计是手动管理内存而非使用 stl 容器，
以及通过直接在高层控制文件指针来读取数据，缺少封装，导致逻辑复杂

综合以上原因，在 project1 完成前，废弃该设计
